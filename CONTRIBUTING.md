# Contributing

Open an issue describing the engineering defect and a synthetic reproducer. Keep changes small and preserve the distinct count, M1 and M2 contracts. Include regression tests for behavioral changes and run the [public bootstrap](docs/REPRODUCIBILITY.md).

Never submit real report/case identifiers, source extracts, licensed terminology, patient material, credentials or unpublished research results. Use clearly artificial fixtures. Declare third-party provenance and licensing. Documentation claims need inspectable evidence and explicit units.

Pull requests are reviewed before merge. Passing synthetic checks does not approve a clinical endpoint, research policy, dataset release or scientific interpretation.
