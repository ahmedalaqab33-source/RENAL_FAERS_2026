# Security and disclosure

Do not post secrets, patient information, real report identifiers or restricted terminology in issues or pull requests. Report software vulnerabilities using GitHub private vulnerability reporting when available; otherwise contact the repository owner through their GitHub profile without posting exploit details publicly.

This repository contains synthetic engineering software, not a clinical decision system. No supported production release or response-time commitment is declared. Before sharing a change, inspect the exact tree and introduced history, verify the manifest, run the content scanner and manually review data and third-party rights. The built-in scanner is a heuristic and cannot certify rights or absence of sensitive data.

Research and data-use concerns remain separate from software defects. MIT covers owner-authored software; it does not grant rights to external data or terminology.
